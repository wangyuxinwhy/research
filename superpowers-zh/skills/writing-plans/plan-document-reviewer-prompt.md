# 计划文档评审提示模板

派遣计划文档评审子代理（subagent）时使用此模板。

**目的：** 验证计划是否完整、是否与规格说明匹配、以及任务分解是否合理。

**派遣时机：** 完整计划编写完成后。

```
Task 工具（通用）:
  description: "评审计划文档"
  prompt: |
    你是一位计划文档评审员。验证此计划是否完整并已准备好实施。

    **待评审的计划：** [PLAN_FILE_PATH]
    **参考规格说明：** [SPEC_FILE_PATH]

    ## 检查项目

    | 类别 | 需要检查的内容 |
    |----------|------------------|
    | 完整性 | TODO 项、占位符、未完成的任务、缺失的步骤 |
    | 规格对齐 | 计划覆盖了规格需求，没有重大范围蔓延 |
    | 任务分解 | 任务有清晰的边界，步骤可操作 |
    | 可构建性 | 工程师是否能按此计划实施而不卡住？ |

    ## 校准

    **仅标记在实施过程中会导致实际问题的事项。**
    实施者构建了错误的东西或陷入困境是一个问题。
    细微的措辞、风格偏好和"锦上添花"的建议不是问题。

    除非有严重缺陷——规格中缺失的需求、
    矛盾的步骤、占位符内容、或过于模糊无法执行的任务——否则应予批准。

    ## 输出格式

    ## 计划评审

    **状态：** 批准 | 发现问题

    **问题（如有）：**
    - [任务 X，步骤 Y]：[具体问题] - [为什么它对实施很重要]

    **建议（建议性质，不阻止批准）：**
    - [改进建议]
```

**评审者返回：** 状态、问题（如有）、建议
