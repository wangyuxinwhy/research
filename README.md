# Research

这个仓库收集了使用 AI 工具（主要是 Claude Code）进行的各种**代码研究**项目。每个项目的代码和文档都由 LLM 辅助生成。

## 什么是代码研究？

代码研究（Code Research）是一种通过**编写和执行代码**来回答技术问题的方法。与其在论坛上问"Redis 能否支持我的通知系统？"，不如直接构建一个概念验证，模拟预期的生产模式，然后通过实验来验证它是否可行。

**关键特点：**

- ✅ 可执行的代码证明可行性
- ✅ 实际的性能数据支持结论
- ✅ 可重现的实验验证假设
- ✅ 从失败中学习和迭代

LLM 可能会产生幻觉和错误，但**代码不会说谎**——如果代码能正确执行并产生预期结果，那就证明了某件事确实可行。

## 异步编码代理

本仓库主要使用**异步编码代理**（如 Claude Code for Web）来进行研究。这种模式的工作流程是：

1. 提出一个明确的研究问题
2. 编写详细的提示词
3. 启动代理让它自主工作
4. 等待代理完成并提交 PR
5. 审查结果和发现

典型的研究任务只需几段提示词，10-15 分钟后就能得到包含代码、测试和详细报告的完整项目。

## 项目理念

- **探索新技术**：通过 AI 辅助研究各种技术主题和实现方案
- **代码优先**：用可执行的代码来回答问题，而不是纯理论分析
- **记录过程**：保持透明度，在提交信息或 PR 中包含提示词和对话链接
- **完全自主**：给代理完整的网络访问权限，让它安装依赖、获取数据、运行实验
- **快速迭代**：每天可以启动多个研究项目，低时间投入，高产出
- **知识积累**：建立一个可供参考的研究项目集合

## 项目结构

每个研究项目都位于独立的目录中，包含：

- 项目的源代码和配置文件
- README.md 说明项目目的、实现细节和发现
- 相关的文档和测试代码

## 关于 AI 生成内容

⚠️ **请注意**：本仓库中的大部分代码和文档由 AI 工具生成，未经过详细的人工审查。这些项目主要用于技术探索和学习，不应直接用于生产环境。

这符合"AI Slop"的定义——AI 生成但未经人工深度审查的内容。我们将这些研究项目集中在这个独立的仓库中，以便：
- 清晰地标识 AI 生成的内容
- 与生产代码库分离
- 作为学习和参考资源

## 高级功能（可选）

### 自动更新 README

可以使用 GitHub Actions 自动为每个项目生成摘要并更新主 README。

Simon Willison 的实现使用：
- [cogapp](https://nedbatchelder.com/code/cog/) - 嵌入 Python 代码的模板工具
- [llm](https://llm.datasette.io/) - LLM 命令行工具
- [llm-github-models](https://github.com/simonw/llm-github-models) - GitHub Models 插件

参考他的 [GitHub Actions 工作流](https://github.com/simonw/research/blob/main/.github/workflows/update-readme.yml)和 [README.md 源码](https://github.com/simonw/research/blob/main/README.md)了解实现细节。

这个功能是可选的，适合在有大量研究项目后再考虑实施。
