# Research

这个仓库收集了使用 AI 工具（主要是 Claude Code）进行的各种技术研究项目。每个项目的代码和文档都由 LLM 辅助生成。

## 项目理念

这个仓库的目的是：

- **探索新技术**：通过 AI 辅助研究各种技术主题和实现方案
- **记录过程**：保持透明度，尽可能在提交信息或 PR 中包含提示词和对话链接
- **实践学习**：每个项目都是一个独立的探索，关注实际问题的解决
- **知识积累**：建立一个可供参考的研究项目集合

## 项目结构

每个研究项目都位于独立的目录中，包含：

- 项目的源代码和配置文件
- README.md 说明项目目的、实现细节和发现
- 相关的文档和测试代码
